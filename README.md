# AR บนกระดาษ (Image Tracking AR) — คู่มือติดตั้ง

หน้าเว็บนี้ใช้ไลบรารี **MindAR** (ฟรี, โอเพนซอร์ส) ทำงานผ่านเบราว์เซอร์มือถือ
โดยตรง ไม่ต้องติดตั้งแอปเพิ่ม เมื่อกล้องเจอภาพที่กำหนดไว้บนกระดาษ โมเดล 3D จะ
โผล่ขึ้นมาเองอัตโนมัติ

ชุดนี้มีไฟล์ครบพร้อมทดสอบแล้ว:
1. `assets/targets.mind` (ไฟล์ภาพเป้าหมายที่คอมไพล์แล้ว)
2. `assets/model.glb` (โมเดล 3D อาคาร)

หากต้องการเปลี่ยนภาพเป้าหมายหรือโมเดลเป็นของตัวเอง ให้ทำตามขั้นตอนที่ 1–3
ด้านล่างแล้วนำไฟล์ใหม่มาแทนที่ 2 ไฟล์นี้ (ใช้ชื่อไฟล์เดิม)

---

## ขั้นตอนที่ 1: เตรียมภาพที่จะพิมพ์ลงกระดาษ

เลือกภาพที่จะใช้เป็น "ตัวกระตุ้น" ให้ AR ปรากฏ ควรมีคุณสมบัติดังนี้:
- มีรายละเอียด ลวดลาย หรือคอนทราสต์เยอะ (หลีกเลี่ยงภาพสีพื้นเรียบๆ หรือลายซ้ำๆ
  เช่น ตารางหมากรุก เพราะระบบจะสับสน)
- เป็นภาพสี่เหลี่ยม ความละเอียดปานกลางพอ (ไม่ต้องสูงมาก)

## ขั้นตอนที่ 2: คอมไพล์ภาพเป็นไฟล์ .mind

1. เปิดเครื่องมือคอมไพล์ฟรีของ MindAR ที่
   **https://hiukim.github.io/mind-ar-js-doc/tools/compile/**
2. ลากภาพจากขั้นตอนที่ 1 เข้าไป
3. รอระบบประมวลผล แล้วกดดาวน์โหลดไฟล์ `targets.mind`
4. นำไฟล์นี้มาแทนที่ `assets/targets.mind` ในโฟลเดอร์นี้

## ขั้นตอนที่ 3: เตรียมไฟล์โมเดล 3D

นำไฟล์ `.glb` ที่แปลงจาก SketchUp มาวางแทนที่ `assets/model.glb`
(ไฟล์ต้องชื่อ `model.glb` พอดี หรือจะแก้ชื่อในโค้ด `index.html` บรรทัดที่มี
`src="./assets/model.glb"` ก็ได้)

### ปรับขนาด/ตำแหน่งโมเดล

สิ่งสำคัญที่ต้องเข้าใจก่อน: **ระนาบภาพเป้าหมายของ MindAR กว้าง 1 หน่วยเสมอ**
ไม่ว่าภาพจริงจะใหญ่แค่ไหน (ความสูงคิดตามสัดส่วนภาพ) จุดกึ่งกลางภาพคือ `0,0,0`
และแกน `+Z` ชี้พุ่งออกจากกระดาษ ดังนั้นโมเดลต้อง "ย่อ" ให้เหลือประมาณ 1 หน่วย
และต้อง "เลื่อน" ให้มาอยู่กึ่งกลางด้วย

โมเดลจาก SketchUp มักมีปัญหา 2 อย่างพร้อมกัน:
1. **ใหญ่เกินไปมาก** (หน่วยเป็นมิลลิเมตร/นิ้ว ตัวเลขจึงเป็นหลักพัน)
2. **ไม่ได้อยู่ที่จุดกำเนิด** ทำให้โผล่เยื้องออกไปนอกกระดาษ แม้ย่อขนาดถูกแล้ว

ของไฟล์ `model.glb` ปัจจุบันวัดได้ดังนี้:

| ค่า | X | Y | Z |
|---|---|---|---|
| ขนาด | 5956.5 | 1326.6 | 1029.5 |
| จุดกึ่งกลาง | 3054.57 | 300.84 | 514.76 |

โมเดลเป็นแบบ **Z-up** (ฐานอยู่ที่ `Z=0` พอดี) ซึ่งตรงกับแกนของระนาบ target อยู่แล้ว
จึงไม่ต้องหมุน — ใช้ `rotation="0 0 0"` ได้เลย ค่าที่ตั้งไว้ใน `index.html` คือ:

```html
<a-gltf-model rotation="0 0 0" position="-0.4093 -0.0403 0"
              scale="0.000134 0.000134 0.000134" src="#model">
```

ที่มาของตัวเลข:
- `scale` = `0.8 / 5956.5` = `0.000134` → อาคารกินพื้นที่ 80% ของความกว้างภาพ
- `position` X,Y = `-(จุดกึ่งกลาง × scale)` เพื่อดึงอาคารมาไว้กึ่งกลางภาพ
- `position` Z = `0` เพราะฐานโมเดลอยู่ที่ `Z=0` อยู่แล้ว อาคารจึงวางแนบบนกระดาษพอดี

**ถ้าเปลี่ยนโมเดลใหม่** ให้วัดขนาดของไฟล์ก่อน (เปิดใน Blender หรือ
https://gltf-viewer.donmccurdy.com/) แล้วคำนวณตามสูตรเดียวกัน:
`scale = 0.8 / ด้านที่ยาวที่สุดในระนาบกระดาษ` และ
`position = -(จุดกึ่งกลาง × scale)`

อยากให้อาคารใหญ่ขึ้น/เล็กลง ก็เปลี่ยนเลข `0.8` เป็นค่าอื่น (เช่น `0.5` = เล็กลง,
`1.2` = ล้นออกนอกภาพ) **แล้วอย่าลืมคำนวณ `position` ใหม่ด้วย** ไม่งั้นอาคารจะเยื้อง

### แอนิเมชัน

`model.glb` ปัจจุบันไม่มีแอนิเมชัน (`animations: 0`) จึงถอดไลบรารี `aframe-extras`
(~1.7 MB) ออกเพื่อให้โหลดเร็วขึ้นบนมือถือ ถ้าเปลี่ยนไปใช้โมเดลที่มีแอนิเมชัน
ให้เปิดบรรทัด `<script>` ของ `aframe-extras` ที่คอมเมนต์ไว้ในส่วน `<head>`
แล้วใส่ attribute `animation-mixer` กลับเข้าไปที่ `<a-gltf-model>`

## ขั้นตอนที่ 4: พิมพ์ภาพลงกระดาษ

พิมพ์ **ภาพเดียวกันเป๊ะๆ** กับที่ใช้คอมไพล์ในขั้นตอนที่ 2 ลงกระดาษ A4
ไม่ควรใช้ภาพอื่นที่แค่คล้ายกัน เพราะระบบจับจุดสังเกตเฉพาะของภาพนั้นไว้แล้ว

## ขั้นตอนที่ 5: โฮสต์ผ่าน HTTPS แล้วทดสอบ

กล้องมือถือจะขอสิทธิ์ใช้งานได้ก็ต่อเมื่อหน้าเว็บเปิดผ่าน **HTTPS** เท่านั้น
(เช่นเดียวกับที่คุยกันไว้เรื่อง Cloudflare Tunnel) เมื่ออัปโหลดทั้งโฟลเดอร์
(`index.html` + โฟลเดอร์ `assets/`) ขึ้นโฮสต์แล้ว เปิดลิงก์จากมือถือ กดปุ่ม
"เปิดกล้อง" อนุญาตสิทธิ์กล้อง แล้วเล็งไปที่กระดาษที่พิมพ์ไว้

## ข้อควรระวัง

- **แสงในห้อง:** แสงน้อยเกินไปหรือสะท้อนแสงจ้าที่กระดาษจะทำให้กล้องจับภาพไม่ได้
  ควรทดสอบในสภาพแสงจริงของห้องเรียนก่อนใช้งานจริง
- **กระดาษยับหรือโค้งงอ:** ควรวางกระดาษให้เรียบที่สุด เพราะการบิดงอทำให้ภาพ
  ต้นแบบเพี้ยนไปจากที่คอมไพล์ไว้
- **ทดสอบก่อนใช้จริง:** ควรลองเปิดใช้งานบนมือถือทั้ง iOS และ Android อย่างน้อย
  เครื่องละ 1 รุ่นก่อนนำไปใช้กับนักเรียนทั้งห้อง
